## Cara Menjalankan Program dari Terminal

Pastikan Python sudah terpasang di komputer dan VS Code sudah berada pada folder repositori.

1. Menjalankan Program Biodata
Buka terminal, kemudian jalankan:
```bash
python latihan/01_biodata.py

Masukkan nama, NIM, kelas, dan tahun lahir sesuai yang diminta program.

Contoh:
Nama: Revania
NIM: 2225250100
Kelas: 3A
Tahun lahir: 2007

Program akan menampilkan kartu biodata beserta perkiraan umur.

2. Menjalankan Program Luas dan Keliling Persegi Panjang
python latihan/02_persegi_panjang.py

Masukkan nilai panjang dan lebar dalam satuan centimeter.

Contoh:

Masukkan panjang (cm): 10
Masukkan lebar (cm): 5

Program akan menampilkan luas dan keliling persegi panjang dengan dua angka desimal.

3. Menjalankan Program Konversi Suhu
python latihan/03_konversi_suhu.py

Masukkan suhu dalam Celsius.

Contoh:

Masukkan suhu Celsius: 25

Program akan menampilkan hasil konversi suhu ke Fahrenheit dan Kelvin.

4. Menjalankan Program Nilai Akhir Mahasiswa
python latihan/04_nilai_akhir.py

Masukkan nama mahasiswa, nilai tugas, UTS, dan UAS.

Contoh:

Nama mahasiswa: Revania
Nilai Tugas: 85
Nilai UTS: 80
Nilai UAS: 90

Program akan menghitung nilai akhir berdasarkan bobot:

Tugas = 20%
UTS = 30%
UAS = 50%
5. Menjalankan Program Kalkulator Koordinat Dua Titik
python latihan/05_koordinat.py

Masukkan koordinat titik A dan titik B.

Contoh:

x titik A: 1
y titik A: 2
x titik B: 4
y titik B: 6

Program akan menghitung perubahan koordinat, jarak antara dua titik, dan titik tengah.
